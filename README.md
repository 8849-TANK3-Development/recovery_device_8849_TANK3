# Device tree for 8849 TANK 3 (TANK 3 PRO)
The 8849 TANK 3 (TANK 3 PRO) (codenamed _"TANK3"_) is a high-end, mid-range smartphone from Unihertz.

It was announced on 2023, October 30. Release date was 2023, November 01.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------

Chipset | Mediatek Dimensity 8200 (4 nm)
GPU     | Mali-G610 MC6
Memory  | 16/18 GB RAM
Shipped Android Version | Android 13
Storage | 512 (UFS 3.1)
Battery | Non-removable Li-Po 23000mAh mAh battery
Display | 1080 x 2460 pixels, 6.79 inches, IPS LCD
